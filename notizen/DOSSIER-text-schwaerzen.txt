========================
Stand: 25.11.2026 · gedacht als Übergabe an eine neue Sitzung.
Satz zum Beginnen: „Lies notizen/DOSSIER-text-schwaerzen.txt und arbeite weiter."

1. WORUM ES GEHT
Text schwärzen entfernt Text aus Bildern, PDFs und Textdateien — auf dem Gerät,
ohne Netz, ohne Konto. Bei PDFs wird jede Seite als Bild neu geschrieben; der Text
ist danach nicht markierbar oder kopierbar. Vier Systeme: Android, Windows, Linux,
macOS. iOS wurde am 24.11.2026 verworfen (kein Xcode, keine Zeit).

5. BAUEN UND AUSLIEFERN
Desktop + Android (öffentliches Repository, kostet Minuten, nicht Speicher):
  gh workflow run bauen.yml -R Suilui1/text-schwaerzen
  gh run watch -R Suilui1/text-schwaerzen
  # Pakete herunterladen und ablegen:
  python3 werkzeuge/austausch.py --neu <datei> --ziel /Volumes/Jammtool --name <name> --alte "<muster>"
Veröffentlichung: Tag setzen und senden — der Bau hängt an Tags v*:
  git tag -a v2.9.0-alpha.2 -m "…" && git push origin v2.9.0-alpha.2
  Der Auftrag „veroeffentlichen" legt das Release an und löscht danach die Zwischenpakete.
  WICHTIG: Danach von Hand als Vorab-Fassung kennzeichnen, das macht der Ablauf nicht:
  gh release edit <tag> --prerelease --notes-file notizen/RELEASE.md

macOS-App (lokal):
  bash werkzeuge/baue_mac_app.sh      # übersetzt, kopiert ins Bündel, setzt Fassung 2.9.0,
                                      # signiert ad-hoc, macht Kopflauf und Startprobe
  Prüfwege:  --selbstpruefung · --info · --frage <datei> · --markieren <datei>

7. FALLEN, DIE SCHON ZUGESCHLAGEN HABEN
· Nach dem Tausch von Contents/MacOS MUSS neu signiert werden, sonst SIGKILL (Taskgated).
· pgrep-Muster mit Umlaut finden nichts („schwärzen" liegt zerlegt auf der Platte) — ohne Umlaut suchen.
· Klick-Brücken (onKlick) niemals als assoziiertes Objekt am Knopf halten: Absturz beim Abbau.
  Jetzt in KlickSpeicher (static) — und die Liste steht NICHT hinter app.run().
· AppKit-Dateidialog ist modal: solange er offen ist, reagiert kein anderes Fenster.
· Nach dem Editor nicht naechste() rufen, ohne editorOffen zu prüfen — sonst beendet sich die App.
· PDF-Weg: Formen müssen an verarbeiteFormen gehen, nicht an das Bild.
· Verwischen: Vorschau 22-fach, Ergebnis 16-fach (Julius: Vorschau gut, Ergebnis war zu stark).
· Stempel: Schriftgröße aus Kasten (Höhe UND Breite), sonst quillt der Text heraus.
· Kein Teilneuzeichnen beim Ziehen — das erzeugt Rastermuster.
· Android: Signaturschlüssel seit 2.1.x gleich; neue APK installiert über die alte.

9. VERHALTEN GEGENÜBER JULIUS
Deutsch, kurz, mit gemessenen Zahlen. Er entscheidet Umfang und Tempo. Nichts löschen,
ohne die neue Kopie geprüft zu haben (Prüfsumme). Fehler offen benennen: sagen, beheben,
prüfen, aufschreiben. Für Tests vom Stick: selbsttest.bat, Bericht zurück.
